## Основной инструмент для кодинга

**DeepSeek V4 Pro** — ваша основная рабочая лошадка для 80% задач кодинга. Лучший выбор для сложных алгоритмов, рефакторинга и работы с большими файлами (контекст 1M токенов). Оставьте её моделью по умолчанию.

Другие модели используйте как специализированные инструменты для специфических сценариев.

## Быстрый выбор модели

| Ситуация | Модель | Команда |
| :--- | :--- | :--- |
| Основной кодинг (по умолчанию) | DeepSeek V4 Pro | `/model DeepSeek V4 Pro` |
| Исследование / анализ кода (бесплатно) | MiMo V2.5 Free | `/model MiMo V2.5 Free` |
| Спроектировать архитектуру | Kimi K2.6 | `/model Kimi K2.6` |
| Сложная многошаговая задача | Qwen3.7 Max | `/model Qwen3.7 Max` |
| Экономичный кодинг / бэкап | MiMo-V2.5-Pro | `/model MiMo-V2.5-Pro` |
| Проанализировать скриншот/схему | MiniMax M3 | `/model MiniMax M3` |
| Быстрая правка / рутина | DeepSeek V4 Flash | `/model DeepSeek V4 Flash` |
| Бесплатный план Б (когда Go кончился) | MiMo V2.5 Free | `/model MiMo V2.5 Free` |

## Важные советы

1. DeepSeek V4 Pro — ваша основная модель для кодинга. Держите её по умолчанию.

2. Для исследования кода, поиска информации и анализа используйте MiMo V2.5 Free — это лучшая бесплатная модель для этих задач, она видит изображения и имеет контекст 1M.

3. Начинайте с Kimi K2.6, если задача сложная и непонятная — она спроектирует решение.

4. Для длительных автономных задач (создать микросервис с нуля) используйте Qwen3.7 Max.

5. MiMo-V2.5-Pro — отличный бэкап, если DeepSeek V4 Pro буксует или нужно сэкономить лимиты.

6. DeepSeek V4 Flash используйте только для быстрых правок — не тратьте дорогие модели на переименование переменных.

7. Когда лимиты Go кончились — переключайтесь на MiMo V2.5 Free. Она лучшая среди бесплатных и закроет и исследование, и простой кодинг.
