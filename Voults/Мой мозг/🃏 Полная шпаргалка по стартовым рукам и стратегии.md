## 1. Базовые понятия (Ауты, ставки, математика)

### Ауты и правило 2-4
- **Аут** — карта, которая делает твою руку лучшей (нутом или почти нутом).
- **На флопе:** умножаем ауты на **4** → % попадания к риверу.
- **На терне:** умножаем ауты на **2** → % попадания на ривере.

| Аутов | На терне (x2) | На флопе (x4) |
|-------|---------------|---------------|
| 4     | 8%            | 16%           |
| 8     | 16%           | 32%           |
| 9     | 18%           | 36%           |
| 12    | 24%           | 48%           |
| 15    | 30%           | 60%           |

> **Важно:** Правило x4 работает точно только до 9 аутов. Если больше 9, погрешность растет.

---

### Ставки на ценность (Value Bet)
**Value Bet** — ставка с сильной рукой, чтобы получить колл от более слабой руки.

| Тип Value Bet | Размер ставки | Пример |
| :--- | :--- | :--- |
| **Толстая ценность** | 2/3 — 3/4 банка | Сет против топ-пары |
| **Тонкая ценность** | 1/3 — 1/2 банка | Топ-пара со слабым кикером |
| **Очень тонкая** | 1/4 — 1/3 банка | Средняя пара на безопасной доске |

**Главное правило:** Ты ставишь на ценность, только если уверен, что оппонент заколлирует с худшей рукой.

---

### Размер ставок и математика (RFE)
**RFE (Required Fold Equity)** — сколько % рук оппонент должен сбросить, чтобы твой блеф окупился.

**Формула:** `RFE = Ставка / (Ставка + Банк)`

| Ставка | RFE |
| :--- | :--- |
| 1/3 банка | 25% |
| 1/2 банка | 33% |
| 2/3 банка | 40% |
| Банк | 50% |

**Почему 2/3 банка против дро:**  
- У оппонента флеш-дро (9 аутов = 36% на победу).  
- Ставка 2/3 банка даёт ему шансы банка 28%.  
- **28% < 36%** → ему математически невыгодно коллировать.

## 2. Банкролл-менеджмент (BRM)

### Кэш-игра
- **Минимальный BR:** 20 бай-инов (BI)
- **Комфортный BR:** 30 BI
- **Консервативный BR:** 50 BI

| Лимит | Бай-ин | 20 BI | 30 BI | 50 BI |
| :--- | :--- | :--- | :--- | :--- |
| NL2 | $2 | $40 | $60 | $100 |
| NL5 | $5 | $100 | $150 | $250 |
| NL10 | $10 | $200 | $300 | $500 |
| NL25 | $25 | $500 | $750 | $1,250 |

### Турниры (SnG / MTT)
- **SnG (6-max):** 40–60 BI
- **MTT:** 100–200 BI

**Правило апстрима:** Переходи на следующий лимит только при 30 BI для него.

**Стоп-лосс:** Не проигрывай больше 3 BI за сессию.

## 3. Префлоп-стратегия по позициям

### Размер рейза:
- **100+ BB (глубокий стек):** 3–4 BB
- **50 BB (короткий стек):** 2–2.5 BB

### Против лимперов:
**Формула:** `3–4 BB + (1 BB × кол-во лимперов)`

### Стандартные диапазоны:

| Позиция | Руки |
| :--- | :--- |
| **UTG (ранняя)** | AA, KK, QQ, JJ, TT, AK, AQs |
| **MP (средняя)** | Добавляем: 99, 88, AQo, AJs, KQs |
| **CO/BTN (поздняя)** | Добавляем: 77-22, A2s+, KTs+, QTs+, JTs, T9s, 98s |

## 4. Стартовые руки: полный разбор

### 🔴 AA, KK (Монстры)

| Ситуация | Действие |
| :--- | :--- |
| Префлоп, никто не рейзил | Рейз 3–4 BB |
| Кто-то рейзит | 3-бет |
| Кто-то 3-бетит | 4-бет / олл-ин (на 50 BB — олл-ин) |
| Кто-то 4-бетит | Олл-ин (100 BB) / колл (50 BB) |
| Олл-ин от оппонента | Мгновенный колл |

**Флоп с A (для KK):** Чек или 1/3 банка (контроль). Если оппонент агрессирует — фолд.

---

### 🟠 QQ (Дамы)

| Ситуация | Действие |
| :--- | :--- |
| Префлоп, никто не рейзил | Рейз 3 BB |
| Кто-то рейзит | 3-бет |
| Кто-то 3-бетит | 4-бет (лузовый) / колл (тайтовый) |
| Кто-то 4-бетит | Колл (не олл-ин!) |
| Олл-ин | Фолд (против тайтового) / колл (против лузового) |

**Флоп с A/K:** Чек. Если оппонент агрессирует — фолд.

---

### 🟡 JJ (Валеты)

| Ситуация | Действие |
| :--- | :--- |
| Префлоп, никто не рейзил | Рейз 3 BB |
| Кто-то рейзит | 3-бет |
| Кто-то 3-бетит | **Колл** (никогда не 4-беть!) |
| Кто-то 4-бетит | **Фолд** |
| Олл-ин | **Фолд** (кроме маньяков) |

**Флоп с A/K/Q:** Чек. Если оппонент агрессирует — фолд.

---

### 🟢 TT (Десятки)

| Ситуация | Действие |
| :--- | :--- |
| Префлоп, никто не рейзил | Рейз 3 BB |
| Кто-то рейзит | 3-бет (в позиции) / колл (вне позиции) |
| Кто-то 3-бетит | **Колл** |
| Кто-то 4-бетит | **Фолд** |
| Олл-ин | **Фолд** |

**Флоп:** Попал в сет — ставь 2/3. Не попал, есть оверкарта — чек-фолд.

---

### 🔵 99-22 (Мелкие пары)

**99** — пограничная (можно рейзить из любой позиции).  
**88-22** — чистые сет-майнеры.

| Ситуация | Действие |
| :--- | :--- |
| Все сбросились, ты на BTN/CO | **Рейз** (кража блайндов) |
| Кто-то рейзит до тебя | **Колл** (сет-майнинг) |
| Кто-то 3-бетит | **Фолд** (если стек < 100 BB) |
| Кто-то 4-бетит | **Фолд** |

**Флоп:** Попал в сет — ставь 2/3. Не попал — чек-фолд (почти всегда).

> **Золотое правило:** Если ты не поймал сет на флопе — твоя рука ничего не стоит. Сбросил пару — сэкономил стек.

---

### 🟣 Оверкарты (AK, AQ, AJ, KQ, KJ, KT, QJ, JT)

#### AK, AQ (Премиум)

| Ситуация | Действие |
| :--- | :--- |
| Никто не рейзил | Рейз 3 BB |
| Кто-то рейзит | 3-бет |
| Кто-то 3-бетит | 4-бет (лузовый) / колл (тайтовый) |
| 4-бет | Колл (100 BB) / олл-ин (50 BB) |
| Олл-ин | Колл (AK) / фолд (AQ) |

**Постфлоп:** Попал в топ-пару → ставь 2/3. Не попал, есть позиция → C-bet 1/2. Нет позиции → чек-фолд.

#### AJ, AT, KQ, KJ (Сильные)

- Играй только в позиции.
- Против 3-бета: одномастные → колл, разномастные → фолд.
- На постфлопе: попал → ставь 2/3. Не попал → чек-фолд.

#### KT, QJ, JT, A9, K9 (Маргинальные)

- Играй **только на баттоне/катоффе** (кража блайндов).
- Против рейза: только колл с одномастными.
- На постфлопе: попал → ставь 1/2 — 2/3. Не попал → чек-фолд.

### 🟩 Одномастные коннекторы, гапперы и мусор

#### Группа 1: Одномастные коннекторы (`54s`, `65s`, `76s`, `87s`, `98s`, `T9s`, `JTs`)

**Главное правило:** Играй их ТОЛЬКО в позиции (BTN/CO) или из BB против рейза при глубоких стеках (100+ BB). В ранней позиции — сбрасывай (кроме `JTs`, `T9s`).

| Ситуация | Действие | Размер |
| :--- | :--- | :--- |
| Все сбросились, ты на BTN/CO | Рейз | 2.5–3 BB |
| Кто-то рейзит до тебя (100+ BB) | Колл | 3 BB |
| Кто-то 3-бетит | Фолд (кроме JTs/T9s при глубоких стеках) | — |

**Постфлоп:**
- **Попал в дро (флеш или двусторонний стрит):** Ставка 2/3 банка (полублеф).
- **Попал в топ-пару/две пары:** Ставка 2/3 банка (ценность).
- **Не попал:** Чек-фолд.

---

#### Группа 2: Одномастные гапперы (`T8s`, `97s`, `86s`, `75s`, `64s`, `53s`)

**Главное правило:** Играй их ТОЛЬКО на BTN, когда все сбросились. В остальных случаях — ФОЛД.

| Ситуация | Действие |
| :--- | :--- |
| Все сбросились, ты на BTN | Рейз 2.5 BB |
| Кто-то рейзит до тебя | ФОЛД |

**Постфлоп:** Агрессивно только с дро. Без дро — чек-фолд.

---

#### Группа 3: Разномастные коннекторы (`JTo`, `T9o`, `98o`, `87o`)

**Главное правило:** Играй их ТОЛЬКО на BTN для кражи блайндов. В любой другой ситуации — ФОЛД.

| Ситуация | Действие |
| :--- | :--- |
| Все сбросились, ты на BTN | Рейз 2.5 BB (иногда) |
| Кто-то рейзит до тебя | ФОЛД |

**Постфлоп:** Если не попал в топ-пару или стрит-дро — сбрасывай. Без флеш-потенциала играть нечего.

---

#### Группа 4: Мусорные одномастные (`92s`, `84s`, `73s`, `52s`)

**Главное правило:** Играй их ТОЛЬКО против тайтового BB на BTN как блеф-кражу. В остальном — ФОЛД.

| Ситуация | Действие |
| :--- | :--- |
| Все сбросились, ты на BTN, BB — нит | Рейз 2.5 BB (редко) |
| Любая другая ситуация | ФОЛД |

## 6. SnG (5-max) стратегия

### Ранняя стадия (глубокие стеки)
- Играй тайтово-агрессивно (TAG).
- Рейз только с сильными руками.
- Не рискуй стеком без монстра.

### Середина игры (10–15 BB)
- **Push/Fold:** Либо олл-ин, либо фолд.
- Чарты для олл-ина первым (10 BB):
  - **UTG:** AA-99, AK, AQ
  - **MP:** 22+, AT+, A2s+, KQ, KJs+
  - **BTN/SB:** 22+, A2+, K2+, Q8+, J8+, T8+, 98s

### Баттл за баббл
- Используй давление на короткие стеки.
- Не коллируй мусор с короткого стека (ICM).
- Начинай пушить широко против «нитов».

| :--- | :--- | :--- |
| Префлоп-рейз | 3–4 BB | 2–2.5 BB |

## 9. Главные ошибки новичков

1. **Колл с разномастными оверкартами против 3-бета.** → Сбрасывай.
2. **Блеф с оверкартами без позиции.** → Блефуй только в позиции.
3. **Слишком большая ставка на полублефе.** → Ставь 2/3 банка.
4. **Игра с маргинальными оверкартами в ранней позиции.** → Играй только на баттоне.
5. **Неумение сбрасывать мелкие пары без сета.** → Если не попал — выходи.
6. **Переоценка одномастных коннекторов вне позиции.** → Играй их только на BTN/CO.
7. **Колл 3-бета с 87s.** → Это слишком дорого для дро.
8. **Блеф с разномастными коннекторами.** → У них нет эквити.

> **Главная мысль покера:**  
> *«Ты не обязан выигрывать каждую раздачу. Ты обязан принимать правильные математические решения. А если оппоненты не умеют считать — это твоя золотая жила, а не проблема.»*

### Как побороть FOMO после сброса мусора

1. **Математика:** J6о — это мусор. Шанс поймать каре — 0.01%. 
2. **Психология:** Ты видишь только выигрышный сценарий (Survivorship Bias). 9999 раз из 10000 ты проиграл бы.
3. **Стратегия:** Даже если ты поймаешь флоп, ты не выиграешь крупный банк (на доске с тремя шестерками никто не будет платить).
4. **Ритуал:** После сброса отвернись от экрана на 3 секунды. Не смотри на флоп.
5. **EV:** Ты не проиграл деньги — ты их сэкономил. Сброс J6о — это +EV на дистанции.

**Запомни:** Лучше сожалеть о сброшенном мусоре, чем о проигранном стеке.

### Мифы о флеш-рояле и каре

1. **Флеш-рояль** — единственная комбинация, которая бьет каре.
2. **Два игрока не могут собрать флеш-рояль одновременно** (карт не хватит).
3. **Два игрока не могут собрать каре одновременно** (в колоде только 4 карты одного ранга).
4. **Если на доске флеш-рояль** — все игроки делят банк (сплит).
5. **Каре проигрывает только флеш-роялю.** Всё остальное каре бьет.

### Одномастные руки с одной оверкартой (A2s-A9s, K2s-K9s, Q2s-Q9s, J2s-J9s)

**Главное правило:** Играй их ТОЛЬКО ради флеша и стрита. Топ-пара — это ловушка.

| Рука | Где играть | Префлоп | Постфлоп (топ-пара) | Постфлоп (дро) |
| :--- | :--- | :--- | :--- | :--- |
| A2s-A5s | BTN/CO (иногда MP) | Рейз / Колл | ЧЕК (контроль) | Ставка 2/3 |
| A6s-A9s | Только BTN/CO | Рейз (кража) | ЧЕК | Ставка 2/3 |
| K2s-K9s, Q2s-Q9s, J2s-J9s | Только BTN | Рейз (кража) | ЧЕК-ФОЛД | Ставка 2/3 |

**Золотое правило:** Если на флопе нет флеш-дро или стрит-дро — сбрасывай руку, даже если поймал топ-пару (кроме исключений, когда ты в позиции и уверен в блефе оппонента).

### Игра с малого блайнда (SB)

**Главное правило:** Никогда не коллируй с SB (не доплачивай 0.5 BB). Либо рейз (если рука сильная), либо фолд.

**Исключения (когда можно доплатить):**
1. A2s – A5s, если в раздаче уже есть 1–2 лимпера (у тебя младший стрит-дро + флеш).
2. Ты на SB, все сбросились до тебя, и ты делаешь **рейз** (не колл) с A2s–A5s или K2s–K9s (для кражи блайндов).

**Что НЕЛЬЗЯ делать:**
- Коллить с Q2s, J2s, K2s против рейза.
- Коллить с любым мусором, даже одномастным, против нескольких оппонентов.
- Переоценивать топ-пару со слабым кикером на постфлопе.
