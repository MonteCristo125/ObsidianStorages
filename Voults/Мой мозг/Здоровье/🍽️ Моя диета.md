# 🍽️ Средиземноморская, адаптированная

## ✅ Что можно есть каждый день

### Утро
- **Овсянка долгой варки** + ягоды/яблоко + ложка орехов
- Яйца (скрэмбл на оливковом масле)
- Кофе с 1 ч.л. сахара

### Обед и ужин
- **Рыба:** 2-3 раза в неделю (скумбрия, сельдь, семга — запекать)
- **Морепродукты:** Креветки, мидии, кальмары (варёные/запечённые)
- **Мясо:** Курица (бедро без шкуры), индейка, постная говядина
- **Овощи:** Огурцы, перец, морковь, помидоры, руккола — каждый день
- **Бобовые:** Хумус, чечевица, нут — 2-3 раза в неделю
- **Гарниры:** Гречка, рис, варёная картошка, паста из твёрдых сортов
- **Жиры:** Оливковое масло, авокадо, горсть орехов (кешью, фисташки)

### Перекусы
- Яблоко, мандарин, любые ягоды
- Горсть орехов
- Овощи с хумусом

## ⚠️ Адаптированные любимые блюда (можно, но с умом)

| Блюдо | Как сделать полезнее |
|:---|:---|
| **Пельмени/Манты** | Домашний фарш из курицы/индейки + салат из овощей |
| **Пицца** | Домашняя, тонкое тесто, томатный соус, морепродукты/курица |
| **Борщ** | На втором курином бульоне, без зажарки, с 10% сметаной |
| **Шашлык** | Постная свинина, маринад без майонеза, много зелени |
| **Оливье** | Курица вместо колбасы, заправка йогурт + горчица |
| **Селедка под шубой** | Слой майонеза заменить на йогурт + горчица |
| **Крабовые палочки** | Редко, качественные, в салате без майонеза |

---

## ❌ Что ограничить или исключить

| Продукт | Почему |
|:---|:---|
| **Жирная свинина, колбасы** | Насыщенные жиры → рост ЛПНП |
| **Печень** (куриная/говяжья) | Очень много холестерина |
| **Маргарин, магазинная выпечка** | Трансжиры |
| **Соль** | Задерживает жидкость, давление |
| **Сахар, сладкие соки** | Только триглицериды растут |

## 🍷 Алкоголь (можно, но дозированно)

- **Светлое пиво (0.5)** — 1 раз в неделю
- **Сухое вино** — бокал
- **Литр пива** — уже перебор для печени

### Безалкогольное пиво (если хочется вкуса без спирта)
- Лучшие по отзывам: **Stella Artois 0.0** (горечь), **Guinness 0.0** (плотность), **Clausthaler**, **Paradox IPA**
