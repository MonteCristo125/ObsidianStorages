## 📌 Основные правила
- Давление зависит от **веса велосипедиста**, **ширины шин** и **типа покрытия**.
- Для точной настройки используйте **насос с манометром**.
- Проверяйте давление **каждые 2–3 недели** (шины теряют воздух со временем).

## ⚙️ Как подбирать давление

### По весу (ориентир для шин 2,1″ для взрослых)
| Вес, кг | Давление, бар |
|---------|---------------|
| 20–30   | 1,8–2,2 |
| 30–40   | 2,0–2,4 |
| 50–60   | 2,2–2,5 |
| 60–70   | 2,5–2,8 |
| 70–80   | 2,7–3,0 |
| 80–90   | 3,0–3,3 |

> ⚠️ Всегда сверяйтесь с **Max / Min** на вашей покрышке.

### По типу покрытия (общий принцип)
| Покрытие | Давление | Эффект |
|----------|----------|--------|
| Асфальт ровный | ↑ выше | лучше накат |
| Грунт, парк | ↓ ниже | комфорт, сцепление |
| Бездорожье | ↓↓ низкое | мягкость, контроль |

## 🛠️ Алгоритм настройки
1. Посмотреть на шине **Max Pressure** (и **Min**, если есть).
2. Взять насос с манометром.
3. Накачать до **нижней границы** рекомендованного для вашего веса диапазона.
4. Проехать 1–2 км, оценить ощущения.
5. При необходимости подкачать или стравить **по 0,1–0,2 бар** за раз.
6. Для асфальта не доходить до Max – оставлять запас **~0,2 бар** (нагрев при езде).
